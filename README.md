# Particular Things

Finding a good home for things you no longer need, starting with books, shared with people Nate knows.
It comes from his instinct to "find a home for it, don't send it to a landfill": a way to let go of
things without pressuring himself, or others, to throw them away.

**Job to be done.** When I have a particular thing I no longer need, I want to find it a good home
instead of sending it to a landfill, so that it gets used by someone who actually wants it.

This is the code. The community's shelf of books is a separate data repository,
`Worthy-Company/Particular-Things`. The pages load shared code from the `root` repository this folder
sits inside (`../js`, `../css`). What is built, and what is planned, is in `BACKLOG.md`. Tests are in
`test/`; run them with `node test/background.mjs things` from `root`.
